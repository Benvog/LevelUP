1. OVERVIEW
────────────────────────────────────────────────────────────────────────────────

1.1 Product Summary
LevelUp is a solo-use, web-based personal progress tracking application built
around a gamified map experience. Inspired by the stage-progression mechanic
in games like Candy Crush, users navigate a branching world map where each
node represents a Milestone in a specific life area. Completing all tasks
inside a Milestone auto-unlocks the next one, creating a clear, satisfying
sense of forward momentum.

1.2 Problem Statement
Most productivity and goal-tracking apps are either too plain (boring to-do
lists with no engagement) or too complex (too many features that get in the
way). There is no tool that combines the motivational pull of game progression
with the practical structure needed to track real personal goals across
multiple life areas — all in one place, just for you.

1.3 Target User
Solo user (G) — a multi-domain self-improver balancing forex trading,
software development, fitness, and other personal goals simultaneously.

1.4 Vision Statement
"Make locking in feel like leveling up."

────────────────────────────────────────────────────────────────────────────────
2. GOALS & SUCCESS METRICS
────────────────────────────────────────────────────────────────────────────────

Primary Goals:
  - Make tracking progress across multiple life areas visually engaging
  - Create a sense of achievement and momentum through gamified unlocking
  - Keep the experience personal, fast, and distraction-free

Success Metrics:
  - User opens the app at least once daily
  - At least one task is marked complete per session
  - Milestones are consistently progressed over a 30-day period
  - User can navigate from the home screen to any task in under 3 taps/clicks

3. FEATURES & FUNCTIONAL REQUIREMENTS
────────────────────────────────────────────────────────────────────────────────

3.1 HOME SCREEN — World Map Hub
────────────────────────────────────────────────────
Description:
  The landing page of the app. Displays a single master branching map with
  multiple paths forking off — one path per life area. The user can see all
  their active life areas at a glance.

Requirements:
  - Display a central "origin" node from which multiple paths branch out
  - Each branch represents one life area (e.g., Forex, Fitness, Coding,
    Basketball)
  - Each branch shows a visual progress indicator (e.g., how many milestones
    completed vs. total)
  - Completed milestones appear lit/active; locked ones appear dimmed
  - Tapping/clicking a branch zooms into that life area's map
  - Ability to add new life area branches from this screen
  - The map renders in a dark, cinematic aesthetic with glowing path lines

3.2 LIFE AREA MAP — Branch View
────────────────────────────────────────────────────
Description:
  When the user selects a life area branch, they enter a dedicated map
  showing all milestones for that area arranged along a winding path.
  Milestones auto-unlock sequentially as the previous one is fully completed.

Requirements:
  - Display milestones as nodes along a styled winding path (not a straight
    line — it should feel like a journey)
  - Node states:
      [COMPLETED]  Fully lit, shows a checkmark or star icon
      [ACTIVE]     Glowing/highlighted — current milestone to work on
      [LOCKED]     Dimmed, padlock icon, cannot be entered
  - Tapping a completed or active node opens the Milestone Detail screen
  - Tapping a locked node shows a brief tooltip: "Complete [Milestone Name]
    to unlock this"
  - Display overall life area progress (e.g., "3 of 8 milestones complete")
  - Back button returns to the World Map Hub

3.3 MILESTONE DETAIL — Task Board
────────────────────────────────────────────────────
Description:
  Inside each milestone is a task board — a contained set of sub-tasks the
  user must complete. Once all tasks are done, the milestone is marked
  complete and the next one auto-unlocks.

Requirements:
  - Display milestone name, description, and completion status at the top
  - List all tasks under the milestone
  - Each task supports the following types:
      [CHECKBOX]   Simple done / not done toggle
      [HABIT]      Daily repeating task — resets at midnight, streak tracked
      [DATED]      Task with a due date — shows days remaining or overdue
      [JOURNAL]    Task with a notes/journal entry attached — user can write
                   freeform text and save it
  - Tasks can be a mix of types within one milestone
  - Progress bar shows how many tasks are complete (e.g., 4/6 tasks done)
  - When all tasks are complete:
      - Milestone is marked COMPLETED with an animated celebration moment
      - The next milestone on the map auto-unlocks
      - User is prompted to return to the map to see the new unlock
  - Habit tasks show a streak counter (e.g., "7-day streak")
  - Dated tasks show a due date badge with color coding:
      Green = more than 3 days remaining
      Amber = 1–3 days remaining
      Red = overdue

3.4 TASK CREATION & EDITING
────────────────────────────────────────────────────
Description:
  Users can add, edit, and delete tasks inside a milestone, and can add new
  milestones to any life area at any time.

Requirements:
  - "Add Task" button inside each Milestone Detail screen
  - Task creation form includes:
      - Task name (text input)
      - Task type selector (Checkbox / Habit / Dated / Journal)
      - Optional: due date picker (for Dated type)
      - Optional: initial journal note (for Journal type)
  - Tasks can be reordered via drag-and-drop
  - Tasks can be edited or deleted (with confirmation prompt)
  - "Add Milestone" button available from the Life Area Map view
  - Milestone creation includes: name, description (optional), and an
    estimated difficulty level (Easy / Medium / Hard)

3.5 LIFE AREA MANAGEMENT
────────────────────────────────────────────────────
Description:
  Users can create and manage their life area branches from the home screen.

Requirements:
  - "Add Life Area" button on the World Map Hub
  - Each life area has: name, icon (from preset set), and accent color
  - Life areas can be archived (hidden from map without deleting data)
  - Archived life areas can be restored
  - No hard limit on the number of life areas

3.6 STATS & PROGRESS OVERVIEW (Phase 2)
────────────────────────────────────────────────────
Description:
  A simple dashboard summarizing overall progress across all life areas.
  Planned for a future release.

Requirements (Phase 2 scope):
  - Total milestones completed (all time)
  - Active habit streaks per life area
  - Tasks completed this week (bar chart by day)
  - Longest milestone completion streak

4. DESIGN & AESTHETIC REQUIREMENTS
────────────────────────────────────────────────────────────────────────────────

4.1 Visual Style
  - Theme: Dark Futuristic RPG — not medieval, not cartoonish. Think sleek,
    premium, "built different" energy. Like a command center meets a quest log.
  - Background: Deep dark (#0A0A14 range), near-black with subtle depth
  - Accent colors: Glowing purples, teals, and electric blues used sparingly
    to highlight active elements
  - Cards & panels: Glassmorphism-inspired — semi-transparent with soft
    borders, no hard opaque boxes
  - Typography: Bold, clean sans-serif for headings; readable weight for body
  - Map paths: Glowing neon-style lines connecting milestone nodes
  - Icons: Outline style, minimal, modern (no chunky cartoon icons)
  - No gradients used decoratively — only as accents on active/glowing elements

4.2 Responsiveness
  - Fully responsive: works on desktop, tablet, and mobile browsers
  - Mobile-first approach for map navigation (touch-friendly node tap areas)
  - Map should be pannable/zoomable on mobile with pinch gestures

4.3 Interaction Design
  - Milestone unlock animation: short, satisfying — not too long
  - Locked node "shake" feedback when tapped
  - Habit streak increments should feel rewarding (small pulse animation)
  - Page transitions: smooth fades or slides, no jarring cuts

5. TECHNICAL REQUIREMENTS
────────────────────────────────────────────────────────────────────────────────

5.1 Tech Stack (Recommended)
  - Frontend: React.js (component-based, good ecosystem for animations)
  - Styling: Tailwind CSS + custom CSS for glassmorphism/glow effects
  - Animations: Framer Motion or GSAP
  - Map rendering: D3.js or custom SVG-based canvas for the branching map
  - State management: Zustand or React Context
  - Storage: localStorage for MVP (no backend required initially)
  - Build tool: Vite

5.2 Data Persistence
  - MVP: All data stored in browser localStorage (no account needed)
  - Phase 2: Optional cloud sync via a lightweight backend (Node.js + SQLite
    or Supabase)
  - Data exported as JSON on demand (backup feature)

5.3 Performance
  - App must load in under 2 seconds on a standard connection
  - Map animations must run at 60fps on mid-range devices
  - No external API dependencies in MVP (fully offline-capable)

5.4 Browser Support
  - Chrome (latest), Firefox (latest), Edge (latest)
  - Mobile: Chrome for Android, Safari for iOS

6. USER FLOWS
────────────────────────────────────────────────────────────────────────────────

6.1 First-Time Setup
  1. User lands on app
  2. Prompted to name their first life area and pick an icon/color
  3. Prompted to create their first milestone in that area
  4. Prompted to add at least one task to that milestone
  5. Lands on the World Map Hub with their first branch visible

6.2 Daily Use Flow
  1. Open app → World Map Hub
  2. See overview of all life areas and active milestone progress
  3. Tap active milestone on any branch
  4. Check off tasks, log journal entries, mark habits done
  5. If milestone completes → celebrate → see next milestone unlock on map
  6. Return to hub or continue in another life area

6.3 Adding a New Life Area
  1. From World Map Hub → tap "Add Life Area"
  2. Enter name, pick icon, pick accent color
  3. Confirm → new branch appears on the world map
  4. Tap branch → prompted to add first milestone

────────────────────────────────────────────────────────────────────────────────

Phase 1 — MVP

  - Life Area Map with milestone nodes and unlock logic
  - Milestone Detail with all 4 task types
  - Basic task creation/editing
  - localStorage persistence
  - Dark RPG visual theme

Phase 2 — Enhancement
  - Stats & Progress Overview dashboard
  - Cloud sync + user account
  - Browser notifications for habit reminders
  - JSON export/import for data backup
  - Milestone difficulty ratings and XP system

Phase 3 — Polish & Extend
  - Character/avatar system that levels up with progress
  - Customizable map themes
  - Milestone templates library
  - PWA (installable on mobile home screen)
